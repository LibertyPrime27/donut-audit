# Working style for this project

- Do the work with tools right away. Do not just describe what you are about to do.
- If you say you will read a file, edit it, or run a command, make that tool call in the same reply.
- Think step by step before editing code: consider the file as it currently is, edge cases, and what could fail.
- After editing, build or run it to confirm it works before saying it is done.
- When a command or edit fails, read the error, change your approach, and try again instead of repeating the same call.
- Keep going until the task is fully complete, and fix errors yourself.
- Update PROGRESS.md after finishing each step.
- Do not edit injector.csproj by hand through guesswork; it is working.
